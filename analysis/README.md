```
python3 scripts/test_make_tables.py
python3 scripts/plot_fourarm.py
pdflatex supplementary && bibtex supplementary && pdflatex supplementary && pdflatex supplementary
pdflatex main_revised && bibtex main_revised && pdflatex main_revised && pdflatex main_revised
python3 scripts/check_numbers.py .        # run where the .aux/.log files are
```
The main manuscript also needs the Elsevier CAS class files next to it:
- `cas-dc.cls`
- `cas-common.sty`

They are **not** in this project; the supplied `elsarticle.cls` is a different class. Overleaf provides them. `elsarticle-num.bst` is included. The supplement needs only standard TeX Live packages plus that `.bst` file.
