# Oracle positive control
Recovered source, configurations, corruption manifests and 15 retained run records (seeds 100–104, three arms). Checkpoints are excluded. The public runner differs from the recovered runner only in dataset-root selection; the verifier uses the bundled historical snapshot. Launchers use the active Python environment and include all five seeds. Historical absolute paths in text records are sanitized. Numerical results are unchanged.

Install `requirements.txt` in a suitable PyTorch environment. Set `DATASETS_ROOT` to an existing CIFAR-100 dataset directory, or create `_dataset_cache` here. Run from this directory. For a new campaign, use a separate copy of this directory and move the retained `runs/` directory outside it before training to avoid ambiguous run selection. Execute `bash run_mlj_p2.sh 0` on Linux with a suitable GPU. For seed 100 alone use `bash run_pilot.sh 0`. The retained run records can be analyzed without retraining; the root README gives the statistical verification command. Full GPU retraining has not been tested in this release workspace.
